# lab-riscv-asm

## Вариант задания
Необходимо реализовать в виде отдельной функции обработку двумерного массива по варианту.

Вариант задания | Описание
--------------- | -------------
11 | Найти строчку в массиве с минимальной суммой элементов. (N = 5, M = 3)

# Результаты работы
## Результаты работы

* **riscv-algo.asm** - программа на RISC-V ASM
* **algo.c** - программа на Си
* **algo.dump** - дамп-файл программы на Си
* **algo_without_output.c** - программа на Си без вывода
* **algo_w_io.dump** - дамп-файл программы без вывода

# Сборка
Сборка
```
riscv-unknown-elf-gcc -march=rv32i -mabi=ilp32 algo.c -o algo.elf
```
Получение дампа файла
```
riscv-unknown-elf-objdump -D algo.elf > algo.dump
